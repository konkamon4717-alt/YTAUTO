# เพลงประกอบ

วางไฟล์ `.mp3` ในโฟลเดอร์นี้ ระบบจะสุ่มหยิบมาใช้ 1 เพลงต่อคลิป (เปิดเบา ๆ ที่ 7%)
ถ้าไม่มีไฟล์เลย ระบบจะทำคลิปที่มีแต่เสียงพากย์ ไม่พัง

**ต้องเป็นเพลงที่ใช้ได้ฟรีเชิงพาณิชย์จริง ๆ** ไม่งั้นโดน Content ID แล้วรายได้จะตกเป็นของเจ้าของเพลง
แหล่งที่ใช้ได้: Pixabay Music, Free Music Archive (เลือก CC0), YouTube Audio Library

ไฟล์ mp3 ถูก gitignore ไว้ ถ้าจะให้ GitHub Actions ใช้ด้วยต้องเอาบรรทัด
`assets/music/*.mp3` ออกจาก `.gitignore` แล้ว commit เพลงขึ้นไป
