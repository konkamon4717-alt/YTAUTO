# yt-auto — ระบบทำนิทานสั้นลง YouTube Shorts อัตโนมัติ

สร้างคลิปนิทานไทยจบในตอนเดียว ความยาวไม่เกิน 1 นาที แล้วอัปโหลดขึ้น YouTube เองวันละ 3 คลิป
รันบน GitHub Actions ทั้งหมด ไม่ต้องเปิดเครื่องทิ้งไว้ ไม่มีค่าใช้จ่าย

## ขั้นตอนการทำงาน

```
Gemini คิดพล็อต (เช็คไม่ให้ซ้ำของเก่า)
   └─ เขียนนิทาน + แตก 6 ฉาก + ชื่อคลิปหลายภาษา
        └─ edge-tts พากย์ไทยทีละฉาก → ได้จังหวะคำสำหรับทำซับ
             └─ Pollinations วาดภาพแต่ละฉาก (ตัวละครหน้าเดิมทุกฉาก)
                  └─ FFmpeg: ken burns + ซับ + เพลง → 1080x1920
                       └─ YouTube Data API อัปโหลด + ใส่ชื่อหลายภาษา
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `config.yaml` | ตั้งค่าทุกอย่าง — เสียง สไตล์ภาพ ความยาว จำนวนคลิป |
| `src/pipeline.py` | ตัวคุมงานหลัก |
| `src/steps/` | แต่ละขั้นตอนแยกไฟล์ แก้ทีละส่วนได้ |
| `docs/index.html` | หน้า dashboard (เสิร์ฟผ่าน GitHub Pages) |
| `.github/workflows/` | ตัวตั้งเวลาและปุ่มสั่งงาน |
| `data/history.json` | ประวัติเรื่องที่เคยทำ ใช้กันพล็อตซ้ำ |

## เริ่มใช้งาน

อ่าน [SETUP.md](SETUP.md) — มีขั้นตอนครบตั้งแต่ขอ API key จนปล่อยคลิปแรก

## รันในเครื่องตัวเอง

```bash
pip install -r requirements.txt
python -m src.pipeline --count 1 --no-upload --keep
```

ต้องมี `ffmpeg` ใน PATH และไฟล์ฟอนต์ไทยใน `assets/fonts/`
