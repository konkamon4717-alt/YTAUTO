Privacy Policy

yt-auto · ปรับปรุงล่าสุด 17 กันยายน 2026
yt-auto เป็นเครื่องมือส่วนตัวที่เจ้าของใช้เผยแพร่คลิปขึ้นช่อง YouTube ของตัวเองโดยอัตโนมัติ ไม่ได้เปิดให้บุคคลอื่นสมัครหรือเข้าใช้งาน

This is a personal, single-user tool used by its owner to publish videos to their own YouTube channel. It is not offered to other users.

ข้อมูลที่เข้าถึง / Data accessed

แอปขอสิทธิ์เข้าถึงบัญชี YouTube ของเจ้าของแอปเพียงบัญชีเดียว เพื่ออัปโหลดวิดีโอ และตั้งค่าชื่อ คำอธิบาย และภาษาของวิดีโอที่แอปสร้างขึ้นเอง

The app requests access to the owner's own YouTube account only, solely to upload videos and set the title, description, and language metadata of videos it generates.

  • ไม่เก็บ ไม่อ่าน และไม่ประมวลผลข้อมูลของผู้ใช้รายอื่น
  • ไม่เข้าถึงอีเมล รายชื่อผู้ติดต่อ หรือไฟล์ใน Google Drive
  • ไม่อ่านความคิดเห็น ข้อความส่วนตัว หรือข้อมูลผู้ชม

การเก็บรักษาข้อมูล / Data storage

ข้อมูลรับรอง (OAuth refresh token) ถูกเก็บเป็นความลับใน GitHub Actions Secrets ของที่เก็บโค้ดส่วนตัวของเจ้าของ และใช้เพื่อเรียก YouTube Data API เท่านั้น

  • ไม่ถูกส่งต่อให้บุคคลที่สาม
  • ไม่ถูกใช้เพื่อการโฆษณาหรือวิเคราะห์พฤติกรรม
  • ไม่ถูกขายหรือแลกเปลี่ยน

Credentials are stored as encrypted secrets in the owner's own repository and are used only to call the YouTube Data API. They are never shared, sold, or used for advertising.

การเพิกถอนสิทธิ์ / Revoking access

เจ้าของบัญชีสามารถเพิกถอนสิทธิ์ของแอปได้ตลอดเวลาที่ myaccount.google.com/permissions เมื่อเพิกถอนแล้ว แอปจะไม่สามารถเข้าถึงบัญชีได้อีก

เนื้อหาที่สร้างขึ้น / Generated content

วิดีโอที่แอปเผยแพร่สร้างขึ้นด้วยปัญญาประดิษฐ์ และถูกระบุว่าเป็นเนื้อหาสังเคราะห์ ตามข้อกำหนดของ YouTube ทุกครั้ง
